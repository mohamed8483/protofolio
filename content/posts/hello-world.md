Welcome to my blog! This is the first post on my personal website, which I built myself using **React**, **Tailwind CSS**, and **Vite**.

## Why build my own site?

There are many website builders out there, but building my own gave me:

- Full control over the design and every detail
- A place to practice and improve my frontend skills
- Somewhere to publish articles easily using markdown

## How the blog works

Each post is a simple markdown file with a bit of metadata at the top:

```md
---
title: "My post title"
description: "A short summary"
date: "2026-10-01"
tags: ["web development"]
---

Your content here...
```

That's it. Write in markdown, drop the file in, and it appears on the site.
