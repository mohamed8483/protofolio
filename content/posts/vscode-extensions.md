Here are the VS Code extensions I use every day as a web developer.

## 1. ESLint

Catches bugs before you even run the code. It integrates directly into the editor and fixes problems automatically.

## 2. Prettier

Consistent formatting without thinking about it. I configure it once and forget about it.

## 3. Tailwind CSS IntelliSense

If you use Tailwind, this is a must-have. It autocompletes classes and shows you what each one does.

## 4. GitLens

Makes Git history understandable. Seeing who changed what and why directly in the editor is incredibly useful.

## 5. Thunder Client

A lightweight REST API client built into VS Code — perfect for testing endpoints without leaving the editor.

> **Tip:** Don't install too many extensions. Each one slows down your editor a little, so keep only the ones you actually use.
